# Infrastructure as Code (IaC) - Mock Templates

This directory contains Infrastructure as Code (IaC) templates written in HashiCorp Terraform configuration syntax.

> [!NOTE]
> **Devops Demo Only**: This configuration is a mock template for demonstration purposes. It is not intended to be run against a live cloud account. It showcases how infrastructure setup (server provisioning, security group policies, database settings) can be modeled and version-controlled.
